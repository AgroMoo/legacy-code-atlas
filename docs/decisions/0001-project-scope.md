# Decision 0001 — Broaden the project to Internet Reclaimer

- **Status:** Adopted as the current project direction
- **Date:** 2026-11-09
- **Decision authority:** Project initiator / initial steward
- **Scope:** Project mission and repository organization

## Context

The project began as Legacy Code Atlas, focused on finding and assessing historical software. The initiator clarified that the underlying vision is broader: discover overlooked or forgotten digital value across software, AI, blockchain-related public resources, products, research, data, creative works, and unknown future categories.

The project is intended as an open, collaborative, non-profit-in-intent public initiative rather than a venture primarily designed to generate personal profit.

## Decision

1. Use **Internet Reclaimer** as the umbrella project name and mission.
2. Keep the existing public repository as the shared project workspace.
3. Retain **Legacy Code Atlas** and its historical software work as the first specialist workstream; do not discard existing records or tools.
4. Develop a free, open **Internet Reclaimer Skill** to help contributors and AI assistants follow a common evidence-led workflow.
5. Keep discovery open to unknown categories.
6. Require provenance, visible uncertainty, rights-aware handling, safety review, and human oversight for consequential actions.
7. Treat community participation and actual validated discoveries as more meaningful than repository stars or raw record counts.

## Non-goals and safeguards

- No claim of ownership over discovered assets.
- No assumption that dormant, abandoned, public, or archived resources are ownerless or freely reusable.
- No unauthorized wallet access, recovery, transfer, or claims over digital financial assets.
- No bulk mirroring or collection solely to inflate catalog size.
- No claim that the project is a registered nonprofit.
- No automatic commercial exploitation of discoveries.

## Revisit conditions

Revisit this decision if community feedback, legal review, safety findings, or actual participation show that the scope or governance should change.
