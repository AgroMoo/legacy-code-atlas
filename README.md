# Legacy Code Atlas

**A Community-Curated Atlas of Forgotten Software**

Legacy Code Atlas is a public discovery and assessment index for historical software that may still have practical value. It is not a code-hosting mirror and does not claim ownership of indexed projects.

## What we do

Discover → Archaeology → Value assessment → Rights review → Isolated testing → Problem matching → Human validation.

We prioritize attributable primary sources, transparent uncertainty, and safe reuse over raw asset counts.

## Current scope

The first MVP is **Legacy Code Reclaimer**: help people find, understand, assess, and responsibly reuse historical code.

## Important status note

The initial catalog contains **30 planning placeholders**, not 30 discovered or verified projects. A placeholder is not an asset record and must not be presented as evidence of discovery, quality, compatibility, or reuse rights.

## Rights and safety

- Preserve basis and redistribution rights are assessed separately.
- Unknown rights status remains `UNKNOWN`; no redistribution is permitted on that basis.
- By default, publish descriptive metadata and canonical upstream links, not copied source code.
- Never bypass authentication, payment, access controls, or repository restrictions.
- Respect takedown and correction requests; see [GOVERNANCE.md](GOVERNANCE.md) and [SECURITY.md](SECURITY.md).

## Contribute

See [CONTRIBUTING.md](CONTRIBUTING.md), submit an asset suggestion through the issue templates, or use the free [Legacy Code Discovery Skill](skills/legacy-code-discovery/SKILL.md).

## Review states

`QUEUED`, `RUNNING`, `REVIEW_REQUIRED`, `ACCEPTED`, `REJECTED`, `BLOCKED`.

Evidence labels: `FACT`, `INFERENCE`, `UNVERIFIED`, `CONFLICT`, `UNKNOWN`.

## Project principle

**Discover responsibly. Preserve context. Reuse only when the evidence and rights allow it.**
