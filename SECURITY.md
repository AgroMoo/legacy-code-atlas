# Security Policy

Do not submit secrets, access tokens, private keys, personal data, malware, or exploit payloads.

For a vulnerability affecting this repository or its workflows, do not publish exploit details in an issue. Contact the repository maintainer privately through GitHub's security reporting feature if enabled, or use the maintainer's verified GitHub contact channel.

Submissions involving unsafe code should be marked for isolated review. Never execute candidate code on a personal or production machine. Use disposable, network-restricted environments and least privilege.

This project does not guarantee that indexed software is safe, maintained, or suitable for production.
